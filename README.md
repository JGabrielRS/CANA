# Estudos - CANA

Repositório criado para armazenar códigos da resolução de alguns exercícios junto da implementação de algusn algoritmos famosos usados durante os estudos da disciplina de CANA.

## Objetivo

Este repositório tem como objetivo registrar minhas anotações da disciplina, reunir alguns exemplos e servir como material de consulta para revisão de algum dos algoritmos implementados.

## Conteúdo

- Exercícios da disciplina
- Implementação do Quick Sort e Counting Sort
